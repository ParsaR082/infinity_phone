# اینفینیتی فون (Infinity Phone) — فروشگاه تخصصی گوشی‌های هوشمند پرچمدار

یک وب‌سایت تجارت الکترونیک فوق مدرن، لوکس و سینمایی با زبان فارسی و چینش راست‌به‌چپ (RTL)، مبتنی بر انیمیشن‌ها و زبان بصری برنده وب‌سایت **Infinity**.

---

## 🌟 بخش‌ها و ویژگی‌های کلیدی (Key Features)

### ۱. معماری و طراحی بصری (Design System & Motion):
- **تم دارک لوکس و تکنولوژی (Cyber-Luxury Tech):** پس‌زمینه‌های مشکی زغالی و گرافیتی عمیق (`#08080a`) با هایلایت‌های نئونی (`#00f59b`).
- **تایپوگرافی اصیل فارسی:** فونت متغیر وزیرمتن (**Vazirmatn**) با وزن‌های متعدد و فاصله‌گذاری دقیق.
- **انیمیشن‌های اسکرول و ترنزیشن:** حفظ ریتم حرکتی، افکت‌های آشکارسازی متن (Color-Fill Segments) و هماهنگی با GSAP و Lenis.
- **عایق‌بندی LTR:** نمایش صحیح نام‌های لاتین و قطعات سخت‌افزاری (مانند `iPhone 16 Pro Max`، `Snapdragon 8 Elite`، `OLED 120Hz`).

### ۲. بخش‌های صفحه اصلی (Homepage Sections):
1. **هیرو سینمایی (Cinematic Hero):**
   - تیتر بزرگ و الهام‌بخش: «تکنولوژی، فراتر از انتظار»
   - معرفی پرچمدار سال در قابی سه‌بعدی با پس‌زمینه هاله نور و ویدیوی استودیو
   - کارت معلق مشخصات سخت‌افزاری (HUD Specs Card) و دکمه‌های اقدام به خرید
2. **پرچمداران منتخب سال (Featured Smartphones Track):**
   - کارت‌های تعاملی آیفون ۱۶ پرو مکس، گلکسی S25 اولترا، شیائومی ۱۵ اولترا، پیکسل ۹ پرو XL، ناتینگ فون ۲ و وان‌پلاس ۱۲
3. **دنیای برندهای پیشگام (Brand Universe):**
   - کاوش برندهای اپل، سامسونگ، شیائومی، گوگل، ناتینگ و وان‌پلاس با لوگوهای برداری SVG و فیلتر آنی
4. **معماری و نوآوری سخت‌افزاری (Hardware Architecture):**
   - سنسورهای ۱ اینچی دوربین و زوم پریسکوپی
   - نمایشگرهای نسل جدید LTPO AMOLED با رفرش‌ریت ۱۲۰ هرتز
   - پردازنده‌های ۳ نانومتری و هوش مصنوعی روی دستگاه
   - باتری‌های سیلیکون-کربن و شارژ فوق‌سریع ۱۰۰ وات
5. **فروشگاه و جستجوی پیشرفته (Product Collection):**
   - فیلتر بر اساس برند و ظرفیت حافظه (128GB، 256GB، 512GB، 1TB)
   - جستجوی بلادرنگ با پشتیبانی از حروف فارسی و انگلیسی
   - مرتب‌سازی بر اساس محبوب‌ترین، جدیدترین، ارزان‌ترین و گران‌ترین
   - دکمه‌های خرید فوری و افزودن به لیست علاقه‌مندی‌ها
6. **کمپین اختصاصی تیتانیوم (Titanium Editorial Campaign):**
   - معرفی متالورژی تیتانیوم گرید ۵ در پرچمداران نوین
7. **مزایای خرید (Why Shop With Us):**
   - ضمانت ۱۸ ماهه شرکتی
   - رجیستری رسمی در سامانه همتا
   - ارسال اکسپرس و بیمه‌شده
   - ۷ روز مهلت تست و تعویض
8. **فوتر جامع فارسی:**
   - دسترسی سریع به تمام دسته‌ها، قوانین، حریم خصوصی و استانداردهای دسترس‌پذیری

### ۳. صفحات جزئیات محصول (Product Detail Pages - `/product/:slug`):
- مسیردهی داینامیک برای هر گوشی (مانند `/product/apple-iphone-16-pro-max`)
- گالری تصاویر استودیویی با کیفیت بالا و پیش‌نمایش بندانگشتی
- انتخاب رنگ بدنه با پیش‌نمایش رنگ‌های رسمی
- انتخاب ظرفیت حافظه با محاسبه آنی تغییر قیمت
- جدول کامل مشخصات مهندسی (نمایشگر، تراشه، دوربین، باتری، جنس بدنه، وزن و سیستم‌عامل)
- سیستم امتیازدهی و نظرات خریداران

### ۴. فرآیند خرید کلاینت‌ساید (Frontend-Only E-Commerce):
- **سبد خرید کشویی (Cart Drawer):** افزایش/کاهش تعداد، محاسبه خودکار جمع فاکتور به تومان، ذخیره پایدار در `localStorage`.
- **لیست علاقه‌مندی‌ها (Wishlist):** نشانه‌گذاری گوشی‌ها با قلب در تمام کارت‌ها.
- **جستجوی سراسری (Live Search Modal):** پنجره جستجوی زنده با کلید میانبر.
- **تسویه حساب شبیه‌سازی‌شده (Demo Checkout):** فرم اطلاعات پستی، انتخاب روش ارسال، و صدور پیش‌فاکتور رسمی با کد رهگیری پستی و شماره سفارش.

## 🚀 نحوه اجرا با Next.js (How to Run with Next.js)

پروژه به صورت کامل به **Next.js (App Router)** تبدیل شده و با تمام قابلیت‌ها و انیمیشن‌ها آماده اجراست:

### ۱. اجرای حالت توسعه (Development):
```bash
npm run dev
```

### ۲. بیلد و اجرای نسخه نهایی (Production):
```bash
npm run build
npm start
```

### ۳. اجرای سرور قدیمی Node.js (Fallback):
```bash
npm run serve:node
```

سپس در مرورگر خود آدرس زیر را باز فرمایید:
👉 **http://localhost:3000**
